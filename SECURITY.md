# Security Policy

## Supported Versions

Only the latest release of AP Monitor receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of AP Monitor seriously. If you discover a security vulnerability, please do NOT create a public issue on GitHub.

Instead, please send an email to the project maintainers with:
- A description of the vulnerability
- Steps to reproduce or a Proof of Concept (PoC)
- Potential impact and affected components

You should receive an acknowledgment within 48 hours. We will coordinate with you on disclosure timeline and work on a fix before public announcement.
